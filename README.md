# 📖 About

**SmartSchool** is a modern school management platform created to simplify educational processes for students, teachers and school administrators.

The project was born from the idea that many existing electronic diary systems have become outdated both visually and technically. SmartSchool aims to provide a fast, intuitive and attractive alternative with a strong focus on user experience, analytics and maintainable architecture.

Unlike traditional school systems, SmartSchool is designed as a scalable platform where every interface element, component and API endpoint follows a consistent architecture and can evolve together with the project.

# 💻 Frontend

The frontend follows the **Feature-Sliced Design (FSD)** architecture.

## Layers

```text
app
pages
widgets
features
entities
shared
```

This architecture keeps the project scalable, maintainable and easy to extend.
